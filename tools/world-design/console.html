Questions

Do I need to install Python?

No. Python runs right in your browser, on a laptop, a desktop or an iPad.

How is my code checked?

Each task has tests. They run your code and check what it prints and the values it makes.

What if I get stuck?

Every mistake gets a plain explanation. Hints and peeks are there when you want them.

What are Bits?

What you earn for passing. Spend them in the shop on hints, peeks and editor themes.
