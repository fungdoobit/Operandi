Questions

Good to know.

I've never written code. Is this for me?

Yes. It starts from zero: your very first line is a print(). Every new idea comes with an example you can run, and help is always one click away.

Do I need to install anything?

No. Python runs right in your browser, so a laptop or desktop with a modern browser is all you need.

How does the marking work?

When you press Submit, real tests check your code and you get a mark out of 10: all tests passing with tidy code earns a 10. If something's wrong, the feedback tells you what and why, in plain words.

Is it free?

Yes, while it's being built.

Does my progress save?

Yes, in the browser you use. Syncing across your devices is coming.
