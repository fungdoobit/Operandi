# Mittens sprites

Orange tabby sprites by **Carysaurus** ("OrangeTabby_Free_Carysaurus"). The author's terms allow personal and commercial use (Isaac checked, 2026-10-24).

- `run.png` (6 frames) and `idle.png` (12 frames): 48x48 frames, taken from the free pack's sheets.
- `g91.png` (stand to lie), `g92.png` (lying yawn), `g93.png` (sitting yawn), `g94.png` (sitting idle), `g95.png` (sleeping): 64x64 frames rebuilt exactly from GIF previews of the same cat that Isaac supplied (the GIFs are 4x nearest-neighbour enlargements, so nothing was lost). Background removed.

All frames go through one hi-bit pass (Scale3x smoothing, 1-cell outline, rim light, dithered shading) in the boss code, so every animation matches.
