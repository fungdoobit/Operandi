Playtime

    
Learn to think like a programmer by guiding NOVA with Python.

  

  

    
Code is a list of steps. The computer follows them exactly, in order.

    

      
    
      
    
    
  
    
  
    
    
    Mix up the steps and you get something unexpected.
    
    
    
      
      
      
    
      
    
      NOVA works the same way. She does exactly what your code says, in the order you write it, so follow the steps.
      
  
      
  
      
    
      You'll write commands. Each one is a step for NOVA.
      
    
      move() takes NOVA one tile forward
      
    
      
      
      
    
      
    
  
      
  
      
    
      Some commands make NOVA do things.
      
    
      collect() picks up the Bit on NOVA's tile
      
    
      
      
      
      B0
    
      
    
  
      
  
      
    
      Notice the round brackets? They make the command run.
      
    
      No spaces in a name: use an underscoreturn_left()
      
    
      Without the (), Python just names the command and does nothing.
