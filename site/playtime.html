Playtime

    
Learn to think like a programmer by guiding NOVA round a floating island, with real Python.

  

  

    
Code is a list of steps. The computer follows them exactly, in order.

    

      
1Fill the kettle

      
2Boil it

      
3Pour the tea

      
A nice cup of tea

    

  

  

    
You'll write commands. Each one is a step for NOVA.

    
move() takes NOVA one tile forwardmove()

    
collect() picks up a Bit she's standing oncollect()

  

  

    
Notice the round brackets? They make the command run.

    
No spaces in a name: use an underscoreturn_left()

    
Without the (), Python just names the command and does nothing.
