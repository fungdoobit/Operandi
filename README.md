# Operandi

Learn Python from zero with **DOT**, your Digital Operandi Teammate. Lessons, endless challenges, instant marking, Bits, a shop and levels. No AI and no cost.

- `site/`: the standalone web app (deployed on Vercel; see `docs/SETUP.md`)
- `claude-ai-app/`: the "office hours" version that runs inside claude.ai with Claude as teacher
- `tools/validate.mjs`: proves every lesson and challenge template works (`npm run validate`)

Run locally: `npm run serve`, then open http://localhost:8000
